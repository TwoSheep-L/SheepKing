# Generate2SMapSkill

## 技能描述

一个项目路径映射文件生成技能，能够在项目根目录检查并生成`2S.md`文件。遍历当前项目的目录结构，将关键路径按固定格式写入`2S.md`中，方便后续快速查阅项目结构。

## 固定格式说明

`2S.md`文件的固定格式如下：

```
当前文件为自动生成文件,描述了当前项目的关键路径映射关系,请勿手动修改该文件。

这里存放映射路径的数据

/src/main.ts  // 主入口文件
/src/core/BaseAgent.ts  // 基础Agent核心类
...
```

- 第一行：固定说明文字
- 第二行：空行
- 第三行：固定说明文字"这里存放映射路径的数据"
- 第四行：空行
- 后续每行格式为：`路径  // 注释说明`

## 核心功能

### 功能1：检查2S.md是否存在

检查当前项目根目录下是否存在`2S.md`文件。
- 如果存在，直接返回"2S.md 已存在，无需生成"。
- 如果不存在，执行功能2。

### 功能2：遍历项目结构并生成2S.md

遍历当前项目（从工作目录开始），收集重要路径，生成`2S.md`文件。

**需要收集的路径类型：**

1. **核心源码目录**（优先收集）：
   - `/src` 下的所有关键目录和文件
   - 重点关注：`/src/core/`、`/src/skills/`、`/src/tools/`、`/src/services/`、`/src/cli/`

2. **配置文件**：
   - `/package.json`、`/tsconfig.json`、`/.env`、`/base.env`、`/.gitignore`

3. **各Skill路径**：
   - `/src/skills/技能名/` 格式，例如 `/src/skills/FsSkill/  // 文件操作技能`

4. **核心类文件**：
   - `/src/core/类名.ts` 格式

5. **工具文件**：
   - `/src/tools/工具名.ts` 格式

**排除规则**（跳过以下目录/文件）：
- `node_modules/`
- `.git/`
- `.git/` 下的所有内容
- `pnpm-lock.yaml`

**路径格式要求：**
- 路径统一使用 `/` 开头（相对于项目根目录）
- 每条路径后面跟 `  // ` 然后加上中文注释说明
- 目录路径以 `/` 结尾，文件路径不带 `/`
- 按目录层级分组排列，先列目录，再列文件

### 功能3：更新2S.md（可选）

如果用户要求更新，则重新遍历并覆盖生成2S.md。

## 可用工具

本技能可使用以下工具来辅助完成任务：

1. **FsTool** - 文件操作工具（核心工具）
   - 使用 `FsTool` 的 `exists` 操作检查文件是否存在
   - 使用 `FsTool` 的 `treeList` 操作遍历目录结构
   - 使用 `FsTool` 的 `read` 操作读取文件内容
   - 使用 `FsTool` 的 `write` 操作写入2S.md文件

## 工作流程

1. 使用 `FsTool` 的 `exists` 操作检查 `./2S.md` 是否存在
2. 如果存在，返回 "2S.md 已存在，无需生成"
3. 如果不存在，使用 `FsTool` 的 `treeList` 操作遍历项目根目录 `.`
4. 根据遍历结果，提取重要路径，按格式组织内容
5. 使用 `FsTool` 的 `write` 操作写入 `./2S.md`
6. 返回 "2S.md 已生成完毕"

## 注释规则

为路径添加注释时，参考以下映射规则：

| 路径模式 | 注释规则 |
|---------|---------|
| `/src/main.ts` | 主入口文件 |
| `/src/core/*.ts` | 核心模块：具体类名去掉.ts + 对应的描述 |
| `/src/skills/技能名/` | 技能名对应的功能描述 |
| `/src/tools/*.ts` | 工具名对应的功能描述 |
| `/src/services/*.ts` | 服务模块描述 |
| `/src/cli/*.ts` | CLI命令描述 |
| `/package.json` | 项目配置文件 |
| `/tsconfig.json` | TypeScript配置文件 |
| `/.env` | 环境变量配置 |
| `/readme.md` | 项目说明文档 |

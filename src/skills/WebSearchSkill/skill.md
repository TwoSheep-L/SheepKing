# WebSearchSkill - 万能搜索技能

## 技能描述

一个强大的万能联网搜索技能，通过百度搜索引擎爬取各种网络信息，并能够查看指定网页的详细内容。

### 核心能力

1. **万能搜索（BaiduSearchTool）**：搜索百科、商品、新闻、网页等各种内容，返回完整的标题、摘要、链接
2. **网页阅读（WebPageReaderTool）**：读取指定网页的详细内容，自动提取正文，去除广告和导航干扰

## 可用工具

1. **BaiduSearchTool** - 百度爬虫搜索工具
   - 通过百度搜索引擎搜索各种内容
   - 返回完整搜索结果（标题+摘要+链接）
   - 自动处理分页、百科卡片
   - 支持重试和备用方案

2. **WebPageReaderTool** - 网页内容读取工具
   - 获取指定URL的网页内容
   - 智能识别并提取正文（自动模式/文章模式/全文模式）
   - 提取标题、描述、作者、发布时间等元数据
   - 自动去除广告、导航、脚本等干扰元素

## 使用流程

### 流程1：搜索信息

&&&
用户：帮我搜索一下"XXX"的相关信息

步骤1：用户提供搜索关键词
步骤2：调用 BaiduSearchTool，参数为：
  - query = "XXX"
  - page = 0（可选，默认第一页）
步骤3：工具返回搜索结果列表（标题+摘要+链接+来源）
步骤4：整理结果返回给用户
&&&

### 流程2：搜索并查看某个结果的详情

&&&
用户：搜索"XXX"，并帮我看看第一个结果的内容

步骤1：调用 BaiduSearchTool 搜索关键词
步骤2：从搜索结果中获取第一个结果的链接
步骤3：调用 WebPageReaderTool，参数为：
  - url = "第一步结果中的链接"
  - extractMode = "auto"（自动识别正文）
步骤4：返回搜索摘要 + 网页详细内容
&&&

### 流程3：直接查看指定网页

&&&
用户：帮我看一下这个网页的内容 https://example.com

步骤1：用户提供网页URL
步骤2：调用 WebPageReaderTool，参数为：
  - url = "https://example.com"
  - extractMode = "auto"
  - maxLength = 5000（可选）
步骤3：工具返回清洗后的网页正文内容
步骤4：整理结果返回给用户
&&&

### 流程4：搜索百科词条

&&&
用户：帮我查一下"XXX"的百科

步骤1：用户提供搜索词
步骤2：调用 BaiduSearchTool，参数为：
  - query = "XXX 百科"
步骤3：工具返回搜索结果，优先展示百科知识卡片
步骤4：如果结果中有百科链接，调用 WebPageReaderTool 查看详情
步骤5：整理百科内容返回给用户
&&&

### 流程5：搜索商品信息

&&&
用户：搜一下"XXX"这个商品怎么样

步骤1：用户提供商品名称
步骤2：调用 BaiduSearchTool，参数为：
  - query = "XXX 商品 评测"
步骤3：工具返回相关搜索结果
步骤4：根据需要查看具体链接的详情
步骤5：整理商品信息返回给用户
&&&

## 工具参数说明

### BaiduSearchTool 参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| query | string | 是 | 搜索关键词或问题，支持中文 |
| page | number | 否 | 页码，从0开始，默认为0（第一页） |

### WebPageReaderTool 参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| url | string | 是 | 要读取的网页完整URL地址 |
| maxLength | number | 否 | 返回内容的最大字符数，默认3000，最大10000 |
| extractMode | string | 否 | 提取模式：'auto'自动（默认）、'article'正文、'full'全文 |

## 注意事项

1. 搜索时关键词越精确，结果越好
2. 如果搜索结果不够理想，建议调整关键词重新搜索
3. 部分网站可能限制爬虫访问（返回403），此时会尝试备用方案
4. 网页读取时建议使用 auto 模式，会自动判断最佳提取方式
5. 搜索频率过高可能被百度限流，建议每次搜索间隔几秒
6. 对于被屏蔽的网站，可以尝试使用 article 模式
